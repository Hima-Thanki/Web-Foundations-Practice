# CSS Practice

This folder documents my hands-on learning journey with CSS, from basic styling to modern, responsive web layouts.

## Learning Objectives

- Understand CSS syntax, selectors, and specificity.
- Practise colors, typography, and backgrounds.
- Understand the CSS box model.
- Build layouts using Flexbox and CSS Grid.
- Create responsive webpages using media queries.
- Add hover effects and transitions.
- Write clean, reusable CSS.

## Topics and Exercises

| Topic | Practice |
|---|---|
| CSS Selectors | Element, class, and ID selectors |
| Colors and Typography | Colors, fonts, and text styling |
| Box Model | Margin, padding, borders, and sizing |
| Flexbox | Alignment and spacing |
| CSS Grid | Rows, columns, and layouts |
| Responsive Design | Media queries and flexible layouts |
| Effects | Hover states and transitions |
