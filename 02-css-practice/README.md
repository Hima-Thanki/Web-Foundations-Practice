# CSS Practice

Welcome to my CSS practice section. This folder documents my progress in learning CSS and creating modern, responsive web layouts.

## Learning Objectives

- Understand CSS syntax and selectors.
- Practise colors, fonts, and text styling.
- Learn the CSS box model: content, padding, border, and margin.
- Build layouts using Flexbox.
- Create grid layouts using CSS Grid.
- Make websites responsive using media queries.
- Add hover effects and transitions.

## Topics and Exercises

| Topic | Practice |
|---|---|
| CSS Selectors | Element, class, and ID selectors |
| Colors and Typography | Colors, fonts, and text styles |
| Box Model | Margin, padding, borders, and sizing |
| Flexbox | Alignment and spacing |
| CSS Grid | Rows, columns, and card layouts |
| Responsive Design | Media queries and flexible layouts |
| Effects | Hover states and transitions |
