# HTML Practice

This folder contains my hands-on practice with HTML5, from basic page structure to semantic HTML and accessible web content.

## Learning Objectives

- Understand how HTML documents are structured.
- Use headings, paragraphs, links, and images.
- Create ordered and unordered lists.
- Build tables and forms.
- Use semantic HTML elements.
- Follow basic accessibility and SEO practices.

## Topics Covered

| Topic | Description |
|---|---|
| Introduction | What HTML is and how it works |
| Document Structure | DOCTYPE, html, head, and body |
| Text Elements | Headings, paragraphs, and emphasis |
| Links and Images | Navigation, hyperlinks, and images |
| Lists and Tables | Organizing content and data |
| Forms | Inputs, labels, and buttons |
| Semantic HTML | Header, nav, main, section, and footer |
| Accessibility | Writing meaningful and accessible markup |
| SEO Basics | Page titles and metadata |

## Practice Goals

- Write clean, readable HTML.
- Understand the purpose of each HTML element.
- Build accessible, well-structured webpages.
- Practise by modifying examples and creating small pages.
