# Developer Profile Card

A responsive developer profile card built with HTML5 and CSS3 as part of my web development learning journey.

## Live Demo

[View the Developer Profile Card](https://hima-thanki.github.io/Web-Foundations-Practice/01-html-practice/profile-card.html)

## Features

- Clean, modern card layout
- Responsive styling for mobile screens
- Gradient text-based avatar
- Skill badges using Flexbox
- Hover effects and CSS transitions
- GitHub profile link

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- CSS Transitions

## Project Files

- `profile-card.html` — Page structure and content
- `profile-card.css` — Styling, layout, and responsive design

## What I Practised

This project helped me practise semantic HTML, CSS selectors, spacing, Flexbox, responsive design, hover effects, and transitions.
