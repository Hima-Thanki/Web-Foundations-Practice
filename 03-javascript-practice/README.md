This folder documents my hands-on learning journey with JavaScript, from programming fundamentals to interactive webpages and practical projects.

## Learning Objectives

- Understand variables and data types.
- Use operators and conditional statements.
- Practise loops and functions.
- Work with arrays and objects.
- Manipulate the DOM to update webpage content.
- Handle browser events and user interactions.
- Understand modern JavaScript (ES6+).
- Build small projects to reinforce concepts.

## Topics and Exercises

| Topic | Practice |
|---|---|
| Variables | `let`, `const`, and data types |
| Operators | Arithmetic, comparison, and logical operators |
| Conditions | `if`, `else`, and `switch` |
| Loops | `for`, `while`, and array iteration |
| Functions | Parameters, return values, and arrow functions |
| Arrays | Adding, removing, and processing values |
| Objects | Properties, methods, and object manipulation |
| DOM | Selecting and changing HTML elements |
| Events | Clicks, input, and form events |
| Modern JavaScript | Template literals, destructuring, and modules |
