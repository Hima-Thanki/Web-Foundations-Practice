# Web Foundations Practice

My hands-on learning journey in web development, covering HTML, CSS, JavaScript, responsive design, and beginner-friendly projects.

## About This Repository

This repository documents my practical learning as I build a strong foundation in front-end web development. It includes code examples, exercises, and small projects created while learning and practising.

## Learning Goals

- Build well-structured web pages using HTML5.
- Style modern, responsive websites using CSS3.
- Understand JavaScript fundamentals and DOM manipulation.
- Practise responsive layouts for desktop, tablet, and mobile.
- Learn Git and GitHub version control.
- Build interactive mini-projects using HTML, CSS, and JavaScript.
- Document my progress and publish working projects.
